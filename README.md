# Anurag Sindhu — Portfolio

Personal portfolio site for Anurag Sindhu, SDE-3 at Aditya Birla Fashion and Retail Ltd (Aditya Birla Group), Bangalore. Built with Next.js and Tailwind CSS.

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- Tailwind CSS v4
- Vercel Speed Insights / Web Analytics
- Geist font

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```

## Deployment

Deployed on [Vercel](https://vercel.com/).
